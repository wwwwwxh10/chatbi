# 仪表盘新建/编辑 - 页面设计说明（桌面优先）

## 全局设计（适用于两页）

### Layout
- 桌面端采用 12 列栅格 + 固定最大宽度容器（例如 1200–1440px），左右留白自适应。
- 页面主体使用 CSS Grid：列表页为单列纵向结构；编辑页为“左侧表单 + 右侧预览”的双列结构（例如 5/7 或 6/6）。
- 间距采用 8px 体系（8/16/24/32）。

### Meta Information
- 标题：仪表盘
- 描述：创建与编辑仪表盘主题色、布局与配置文件。
- Open Graph：title=仪表盘；description=创建与编辑仪表盘；type=website

### Global Styles（Design Tokens）
- Primary（主题色）：来自仪表盘 theme_color。
- Background：#FFFFFF（页面）/ #F7F8FA（浅灰底区域，可随主题色轻微染色）。
- Text：#1F2329（主文案）/#646A73（次文案）。
- Border：#E5E6EB（默认）；与主题色联动时使用 theme_color 的低透明度（如 12%）。
- Button：
  - Primary：背景=theme_color；hover=加深 6–10%；disabled=降低透明度。
  - Secondary：描边=Border；hover=浅底。
- Link：颜色=theme_color；hover=加深。
- 可读性规则：当 theme_color 过浅时，自动切换按钮文字为深色/增加阴影或改用更深的派生色，保证对比度。

## Page 1：仪表盘列表页

### Page Structure
- 顶部：页面标题区 + 主操作区。
- 内容区：仪表盘列表（表格或卡片列表，二选一即可）。

### Sections & Components
1) 顶部标题栏
- 左侧：H1「仪表盘」。
- 右侧：主按钮「新建仪表盘」（点击进入 /dashboards/new）。

2) 仪表盘列表
- 列表项最小信息：名称；操作「编辑」。
- 列表项支持展示一个小色块（theme_color），用于快速识别主题。
- 空态：文案“暂无仪表盘”；按钮“新建仪表盘”。

### Interaction States
- 点击「编辑」进入 /dashboards/:id/edit。
- 列表加载态：骨架屏或加载条。

## Page 2：仪表盘新建/编辑页

### Page Structure（双列联动）
- 顶部：返回入口 + 页面标题 + 保存按钮。
- 主体：左侧“配置表单区”，右侧“实时预览区”。

### Sections & Components
1) 顶部操作栏
- 左：返回「← 仪表盘」；中：标题（新建/编辑）；右：Primary「保存」。
- 保存按钮状态：
  - 无改动禁用；
  - 有未保存改动高亮；
  - 保存中显示 loading。

2) 左侧：配置表单区（Card 分组）
- 分组 A：主题色
  - 控件：主题色选择器（推荐使用颜色选择器 + HEX 输入框）。
  - 说明：提示“已移除封面，仅使用主题色驱动视觉”。
- 分组 B：配置文件
  - 控件：上传区域（按钮 + 拖拽区皆可）。
  - 上传后展示：文件名、上传时间（可选）、“重新上传”操作。
  - 解析状态条：
    - 成功：绿色/主题色轻提示“解析成功”。
    - 失败：红色提示“解析失败”，展示错误摘要（last_parse_error），并提供“重试/重新上传”。

3) 右侧：实时预览区
- 预览容器（Preview Shell）：
  - 顶部条（Header）、若干卡片（Widget Placeholder）用于呈现“布局联动主题色”的效果。
  - 联动点：Header 背景/底边、按钮主色、选中态描边、卡片强调条、分隔线高亮等使用 theme_color 派生色。
- 解析成功预览：
  - 展示配置文件解析后的结构化概览（例如模块列表/区块数量/关键字段摘要）。
- 解析失败预览：
  - 若存在上一次成功结果：继续展示该结果，并在顶部提示“当前文件解析失败，已保留上次预览”。
  - 若无成功结果：展示空态说明 + 错误摘要。

### Responsive Behavior（可选但建议）
- < 1024px：双列改为上下结构（先表单后预览），保存按钮固定在顶部或底部。

### Leave Protection
- 当你修改主题色或重新上传文件但未保存，点击返回或关闭页面时弹出确认：继续离开/留在页面。
